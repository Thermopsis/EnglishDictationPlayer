# 英语听写播放器 · 1.1

一个简单的 Windows 离线播放器，专注于自动分段、自动选段、手动选段和片段重复。

**[下载 Windows 便携版](https://github.com/Thermopsis/EnglishDictationPlayer/releases/latest)** · 免费使用 · 作者 ThermoXu

从 Releases 下载 `EnglishDictationPlayer-Portable.zip`，解压后双击 `英语听写播放器.exe`。Code → Download ZIP 下载的是源码。

**v1.1 更新：**升级了音频分组后的保存功能，新增独立听写课件与下一段自动播放选项。

## 运行

解压 `PhrasePlayer-Portable.zip`，进入 `PhrasePlayer` 文件夹，双击 `英语听写播放器.exe`。
请把旁边的所有 DLL 和 `英语听写播放器.exe.config` 保留在同一个文件夹。不需要 Python、Node、账号或联网。
适用于普通 Windows 10 / 11；使用系统的 .NET Framework 4.8 和音频解码器。不需要安装本项目的开发依赖。

## 使用

1. 点击 **打开音频**，或把音频文件拖进窗口。已实测 MP3、WAV、M4A；其他格式是否可用取决于系统解码器。
2. 软件自动分析停顿，划分短语并选中第一段。**单击波形**可选中所在短语，**上一段 / 下一段**或下拉框可切换。
3. 在波形上按住鼠标左键拖动，可以选择任意片段，包括单词的一部分。反向拖动也可以。
4. 设置 **播放次数**（1、2、3、5、10 次或无限）和 **间隔**（0–30 秒），点击 **播放**。
5. 默认播完当前段就停止。勾选 **播完进入下一段**，会按照设定次数和间隔逐段播放；无限循环会一直停留在当前段。手动片段播完不会自动跳到其他段。

6. **倍速**可选 0.5、0.8、1.0、1.2、1.5、2.0 倍，变速保留音调。播放或暂停时切换会从当前位置继续，可能有短暂切换间隙。
7. **从头播放到尾**会从音频开头连续播到结尾，包含停顿，忽略分段、重复次数和重复间隔；仍支持倍速、暂停 / 继续和 Esc 停止。切换片段会退出全文播放。

播放时按钮可暂停和继续；重复间隔期间按钮变为“停止”，点击即结束本次循环。

## 快捷键和波形

- 空格：播放 / 暂停 / 继续；间隔期间为停止。
- Enter：从当前片段开头重新开始。
- 左右方向键：上一段 / 下一段。
- Esc：停止。
- 波形上滚轮：缩放；下方滚动条：浏览其他时间位置。

在次数下拉框和数字输入框中，方向键保留正常编辑功能；点击波形后即可使用播放快捷键。

## 调整分段

点击 **分段设置**：

- 最短 / 最长片段：默认 2–8 秒，最短可设 0.2–30 秒，最长可设 2–30 秒；最短不能大于最长。没有明显停顿的长语音也会在较安静的位置切成短段。
- 分段停顿：默认 300 毫秒。分得太碎时增大这个值。
- 静音阈值：默认相对 -26 dB。噪声影响分段时可调高；低声内容漏掉时可调低。

- 常用推荐：短语练习 1–5 秒、常规听写 2–8 秒、长句练习 4–15 秒。选择后会自动填写参数，也可自行调整。
- 合并过短片段：默认开启，低于最短值的短段优先与下一段连接，适合 however 等短词。关闭会保留短段。不跨越超过 1.5 秒的无声间隔；孤立短段或无法满足区间的尾段可能短于最短值，内容仍会保留。

点击 **重新分段**应用。分段根据声音和停顿判断，不识别文字，不保证每段是语法完整的句子。必要时用鼠标拖选。
原音频不会被改写，也不会产生一堆分割的音频文件。

## 设置和临时文件

重复次数、间隔、自动切段、倍速和分段参数保存在 `%LOCALAPPDATA%\PhrasePlayer\settings.xml`，再次打开会保留。
本版每次打开音频后从第一段开始，不记录上次音频路径或播放进度。
为准确播放片段，音频在系统临时目录解码为 22.05 kHz 单声道 WAV，正常关闭或换文件时自动清理。约每小时需要 159 MB 临时空间。

## 源码和构建

`source/` 是完整 C# 源码；`build.ps1` 使用随源码提供的官方 Roslyn C# 编译器，无需安装 Visual Studio；构建需要 .NET Framework 4.8。
音频库为官方 NuGet NAudio 1.10.0 的 net35 程序集，用于兼容 Windows 自带运行时并保持体积小。
从项目目录运行 `powershell -ExecutionPolicy Bypass -File .\build.ps1`，输出到 `dist\PhrasePlayer\`。
在构建结果旁保留音频库，然后执行 `英语听写播放器.exe --self-test <测试输出目录>` 可运行音频功能测试。测试会在指定目录生成少量测试音频，不建议选择个人资料目录。

- **语言 / Language**：中文或 English，包含主界面、分段设置、帮助与提示文案。

## 分段编辑与听写改进（1.0）

- **开头预留**：分段设置中默认 0.3 秒，可设置 0–1 秒。较轻的句首仍漏掉时，可增加到 0.5 秒或调低静音阈值。按能量分析，不保证识别所有低声发音；预留不会越过上一段已占用的结尾。
- **合并下一段**：把当前自动片段与下一段连接，包含中间停顿。
- **在此拆分**：在自动片段内部单击波形放置灰色虚线光标，再点击按钮；拆分后两侧至少各 0.1 秒。
- **撤销**：恢复最近最多 20 次自动片段编辑。未保存为课件的编辑仅保留在本次会话，重新打开文件或重新分段会重置，不改写音频。
- **放大 / 缩小 / 显示全部**：按钮调整时间视野；默认最多显示 120 秒，滚动条浏览位置。主窗口波形高度缩小约 20%。
- 设置中的 **显示边界微调** 默认关闭；启用后起点和终点可分别 ±0.1 秒，不越过相邻片段，片段至少保留 0.1 秒。也可微调拖选的手动范围。
- 设置中的 **按片段长度自动留白** 默认关闭；开启后等待时间 = 原始片段时长 × 倍数（0.5–5 倍，默认 2 倍，上限 120 秒），代替主界面的固定间隔，不影响全文连续播放。
- 关于显示：英语听写播放器，轻便的 Windows 离线英语听写工具；作者 ThermoXu；版本 1.1；免费使用。
## 教师模式：提前备课与保存分段

1. 打开音频，在主窗口勾选 **教师模式**。
2. 先自动分段，再按需要合并、拆分或微调边界。也可以拖动选择一个手动练习范围。
3. 点击 **保存课件**，保存为 `课程名称.edlesson`。
4. 下次点击 **打开音频** 选择这个课件，或将课件拖入窗口，即可恢复保存的全部分段，**不会重新自动分段**。
5. 可以把课件移动到其他文件夹，或发给使用此新版播放器的学生，不需要另附原音频。

课件内包含原音频（字节保持不变）、所有分段起止时间及保存时的选中段；如果当时选中手动范围，该范围也会恢复。原音频不被改写；课件不是 MP3，需要本次新版播放器打开，旧 1.0 版本不支持课件。

课件是手动保存，修改分段后请再次保存；关闭或切换文件前会提示未保存的课件修改。取消保存或保存失败不覆盖已有课件。打开课件后仍可继续编辑，并另存或覆盖保存。重新分段会以当前本机参数重建片段，请先保存原课件。

教师模式开关会保留；学生无需开启教师模式也能打开课件。播放次数、速度、语言与皮肤沿用各自本机设置，不由课件覆盖。单个嵌入音频最大 2 GB；保存前请保留可读取的原音频，保存成功后课件即可独立使用。
## 手动点击下一段后自动播放

在 **设置** 勾选 **切换下一段时自动播放（含右方向键）**，然后保存。默认关闭，关闭时只切换片段；开启后点击“下一段”或按右方向键，自动从新片段开头播放，并沿用当前重复次数、间隔及倍速。

上一段、波形单击、短语下拉框仍只选段；末段点击下一段不自动重播。本开关与“播完进入下一段”独立，并会保存到本机设置，下次打开保留。
