# Mac 版与 Windows v1.1 对照

| 项目 | Mac 实现 |
| --- | --- |
| 独立桌面应用 | SwiftUI + AVFoundation 原生 .app，无第三方运行时 |
| Apple Silicon / Intel | Universal 二进制，部署目标 macOS 13+ |
| 自动短语分段 | 移植原版能量 / 停顿算法，后台流式分析 |
| 最短 / 最长与三种推荐 | 1–5 / 2–8 / 4–15 秒，可自定义 |
| 短词合并、句首预留 | 与原型对应，预留默认 0.3 秒，可调至 1 秒 |
| 手动选择、合并、拆分 | 波形拖选、虚线光标、最多 20 步撤销 |
| 缩放与时间浏览 | 放大、缩小、显示全部、滑块与捏合手势 |
| 重复与自动下一段 | 1 / 2 / 3 / 5 / 10 / 无限，固定 / 可选自动留白 |
| 下一段立即播放 | 可选，默认关闭，按钮与右方向键共用 |
| 六档倍速 | 原生 AVAudioUnitTimePitch，保持音调 |
| 全文播放 | 从头到尾连续播放，可暂停和变速 |
| 教师课件 | 内含原音频与精确分段，重新打开不自动分段 |
| Windows 课件互通 | 使用共同音频格式时双向兼容 |
| 默认 / 黑色，中文 / English | 原生界面与帮助、关于、设置持久化 |
| Mac 快捷键 | ⌘O / ⌘S / ⌘, 及空格、方向键、Return、Esc、F1 |
| 作者与免费说明 | ThermoXu，免费使用，版本 1.1 |
| 安装包 | ZIP 与 DMG；ad-hoc 签名，无 Apple Developer ID 公证 |

Mac 的窗口、菜单、文件选择器与控件采用系统原生外观；功能与流程参考 Windows 原型。WMA 需先转为 MP3/WAV；AIFF/CAF 课件仅 Mac 支持。测试结果另见 TEST_REPORT.md。
