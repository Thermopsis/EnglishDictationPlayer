## 音频与算法

- WAV 分块读取、峰值 / 能量分析、相对静音阈值和默认分段。
- 句首预留、低声音量、短引导词优先合并下一段、关闭合并保留短词。
- 连续长语音的时长区间、尾段平衡、完整时间覆盖及无法满足最短值时保留内容。
- 静音文件不生成虚假片段；100 组重复 / 自动切段逻辑；手动选区无限重复。
- 自动留白倍数与 120 秒上限；教师模式、语言、皮肤及下一段播放设置往返保存。
- AVAudioEngine / AVAudioUnitTimePitch 六档实际离线渲染：输出非零，时长符合变速比例，440 Hz 信号变速后仍在频率容差内。
- 十分钟测试 WAV 流式分析：Apple Silicon 141 ms；Intel 993 ms；均生成 60,000 个分析窗口。此为 CI 中的测试 WAV 和缓存条件，不能代表所有编码格式、录音长度或实体设备的速度。

## 教师课件互通

- Mac 保存原音频字节、准确分段、当前片段 / 手动选区；移动文件后恢复；覆盖保存仍保持数据。
- Windows v1.1 课件在 Mac 上恢复，未调用自动分段。
- 将最终 Mac 测试课件交给原 Windows v1.1 `LessonFile.Open` 和 `AudioLoader.Load`：精确边界、手动范围恢复，内嵌 WAV 可由 Windows Media Foundation 解码。
- 无效版本、越界 / 重叠 / 非有限时间、非法音频路径、XML 外部实体均拒绝。读取 / 解压有大小上限，只写受控临时目录；保存完成后替换已有文件。

## 原生窗口检查

真实创建应用窗口并打开课件；检查“下一段”关闭自动播放时不启动音频；拆分 / 合并后时间点一致；边界微调与撤销；手动范围；缩放与显示全部；中英文 / 默认与黑色模式；设置、分段弹窗实际呈现。截图由应用自身视图生成。

波形用原生 Core Graphics 绘制，避免对虚拟显卡 Metal 渲染能力的依赖。音频分析、分段计算和课件读写在后台进行；界面只绘制当前视野。

## 范围与限制

- 自动测试包含原生音频离线渲染和窗口冒烟检查；没有声称完成实体 Mac 扬声器的人工听音、全部用户设备的长期使用或 60 FPS 测量。
- macOS 13 是编译部署目标；本次实际运行环境是 macOS 14 / 15。
- WMA 请先转换。AIFF / CAF 课件仅 Mac 支持；MP3 / WAV / M4A 等共同格式可与 Windows v1.1 互通。
- 本次为 ad-hoc 签名而非 Apple 公证。首次打开可能需要用户在系统中确认；单位管理策略可能要求公证版。
- 课件需要手动保存；本机播放偏好不由课件覆盖。单个嵌入音频最大 2 GB。
